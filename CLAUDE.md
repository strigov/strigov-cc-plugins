# Инструкции Claude Code

Перед любыми изменениями в этом репозитории полностью прочитайте и соблюдайте `AGENTS.md`. Это канонический release runbook для marketplace.

Ключевое правило: при публикации плагина целевая версия и description берутся из удалённого `.claude-plugin/plugin.json` исходного репозитория, а публикуемая запись меняется в `.claude-plugin/marketplace.json`. Обновление только README не является публикацией.

Источник плагина указывается в записи каталога как `{"source": "url", "url": "https://github.com/strigov/<repo>.git"}` — git-тип с явным HTTPS. Форма `{"source": "github", "repo": "..."}` запрещена: для неё Claude Code клонирует по SSH и падает без SSH-ключа. Подробности и остальные поддерживаемые типы — в разделе «Формат `source` в записях каталога» в `AGENTS.md`.

Не копируйте README в этот файл и не записывайте сюда текущие номера версий. При обычном version bump `AGENTS.md` и `CLAUDE.md` не изменяются.
